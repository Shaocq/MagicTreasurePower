## 使用注意

- 运行时取 Buff 预设：`GameplayDataSettings.Buffs` 只公开了流血、饥饿、燃烧、负重等少数几个命名属性；
  全部预设只在私有字段 `allBuffs`（`List<Buff>`）里，需要反射取出，再按 `Buff.ID` 查找。
- 添加：`character.AddBuff(Buff buffPrefab, CharacterMainControl fromWho = null, int overrideWeaponID = 0)`；
  注意它会先检查 `buffResist`，同 ID 已存在时只叠加层数。
- 移除：`character.GetBuffManager().RemoveBuff(int buffID, bool removeOneLayer)`，或
  `RemoveBuff(Buff, bool)` / `RemoveBuffsByTag(BuffExclusiveTags, bool)`。
- 查询：`GetBuffManager().Buffs`（`ReadOnlyCollection<Buff>`）、`HasBuff(int)`、`GetBuffByTag(tag)`。

按 ID 取预设（反射 `allBuffs`，建议初始化时取一次并缓存成字典）：

```csharp
FieldInfo field = typeof(GameplayDataSettings.BuffsData)
    .GetField("allBuffs", BindingFlags.Instance | BindingFlags.NonPublic);
var all = (List<Buff>)field.GetValue(GameplayDataSettings.Buffs);
Dictionary<int, Buff> map = all.Where(b => b != null).GroupBy(b => b.ID)
    .ToDictionary(g => g.Key, g => g.First());
```
- `隐藏 = 是` 的条目是内部 Buff（抗性触发、食物残留、装备内置等），一般不要直接展示或操作。
- 同名条目（如 `Buff_BleedS`、`Buff_Hurt`）是不同 ID 的变体，**按 ID 区分，不要按名字**。
- 「持续时间」是 `totalLifeTime`；限时条目记 `limitedLifeTime = true`。
