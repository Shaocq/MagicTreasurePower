订阅前置 HarmonyLib（工坊 `3589088839`）并置于本 mod **之前**加载，然后在创意工坊订阅「法宝之力」，或把 `MagicTreasurePower` 文件夹放入 `Duckov_Data\Mods\`。

| 金蛟剪 | 每次射击有 30% 概率触发；命中敌人时：若自身带有异常状态则随机移除其中一种的一层，否则获得一个随机增益（持续 8 秒）；不同增益可同时存在，重复获得同一增益时持续时间累加。 |
| 九龙离火罩 | 装备时：身体与头部护甲 +5，火、毒、电、空间、幽灵、冰六种元素抗性各 +20%，背包容量 +20 格。 |

实现方式：每件法宝挂一个原版 `Effect` 组件（`triggers` / `filters` / `actions` 全为空，**纯展示**），
详情面板的属性区会以单行文本显示 `Effect.Description`。模板（Character 占位物品）自带的
「枪械伤害倍率 +100%」等显示词条已全部隐藏。

生效条件：法宝必须装备在六个「法宝」槽位之一，换下立即失效。

目前**已实现两件**：

- **混元金斗**（每次射击掷一次骰，30% 概率使该次射击在护甲结算前额外附加
  「枪械基础伤害 × 1.5」的直击伤害；枪械基础伤害取 `Stat.BaseValue`，不含配件加成，
  霰弹枪按 ShotCount 均摊，穿透每段命中都生效，爆炸伤害不加成；
  实现见 `src/Patches/HunYuanJinDouPatch.cs`）。
- **翻天印**（每次射击掷一次骰，20% 概率本次不消耗弹药并额外射出一发；
  额外那发走完整原版射击管线，会真的多一颗弹丸飞出，枪口火光与抛壳不变；
  额外那发**不叠加混元金斗**加成，命中时伤害数字为金色（深棕描边），
  与混元金斗的正红数字（黑描边）区分；
  实现见 `src/Patches/FanTianYinPatch.cs`）。

- **金蛟剪**（每次射击掷一次骰，30% 概率让这一发子弹携带效果；首次命中敌人时生效：
  自身有异常状态则随机移除其中一种的**一层**；没有异常则获得一个原版增益，持续 8 秒。
  不同增益可以同时存在；随机到已经生效的同一个增益时，把它的持续时间累加 8 秒。
  只从白名单随机，避开剧情 Buff、
  依赖装备逻辑的内部 Buff，以及由系统持续重新施加的环境类负面；
  实现见 `src/Patches/JinJiaoJianPatch.cs`）。

- **定海珠**（受到伤害时按等级概率完全免疫（Lv.1~7：8%~20%）；每场战局可免死 1 次，
  Lv.4 起 2 次、Lv.7 起 3 次；受到致命伤害时免疫死亡并把生命值锁定为 1 点 5 秒，
  触发时挂一个自定义「定海珠·护体」Buff 展示状态，换图后次数重置；
  触发瞬间清空身上全部「金蛟剪可清除」类目的异常状态，护体期间同类异常也加不上
  （两份效果共用 `src/Treasures/TreasureDebuffs.cs` 的白名单）；
  实现见 `src/Patches/DingHaiZhuPatch.cs`）。

- **阴阳镜**（常驻：最终伤害 ×0.8，即 20% 乘算减伤，单次伤害最低 1 点；
  拦在 `CurrentHealth` 的 setter 上，只对 `Health.Hurt` 造成的掉血生效，
  并提示本次减免了多少；实现见 `src/Patches/YinYangJingPatch.cs`）。

- **九龙离火罩**（装备期间：身体/头部护甲 +5，火毒电空间幽灵冰六种元素抗性各 +20%，
  背包容量 +20 格。实现为给角色物品的属性挂修饰符，每 0.5 秒比对装备状态同步；
  实现见 `src/Treasures/JiuLongLiHuoZhaoEffect.cs`）。

## 法宝等级

- 每件法宝实例独立升级（进度存在物品 `Variables` 里，随原版存档保存），默认 1 级、上限 7 级。
- 击杀经验：普通敌人 +1、精英 +4、BOSS +9；只算玩家本人最后一击，装备的两件法宝各得全额。
- 升级所需经验：100 / 135 / 198 / 289 / 408 / 555（累计 1685）。
- 曲线：二次递增，二阶差值固定 28。
- 详情页：图标左上角显示 `Lv.N`，属性区顶部显示经验条（当前经验 / 升级所需）；满级显示 `MAX`。
- 等级会影响各法宝的概率与强度；**Lv.7 = 当前正式数值**，低等级按比例下调。

| 法宝 | Lv.1 → Lv.7 |
| --- | --- |
| 翻天印 | 触发 8/10/12/14/16/18/20%；额外子弹伤害 60/65/70/80/85/90/100% |
| 阴阳镜 | 最终减伤 8/10/12/14/16/18/20% |
| 定海珠 | 免伤 8/10/12/14/16/18/20%；免死锁血全等级 5 秒；免死次数 1/1/1/2/2/2/3 次 |
| 混元金斗 | 触发 12/15/18/21/24/27/30%；附加倍率 1.0/1.1/1.2/1.2/1.3/1.4/1.5 |
| 金蛟剪 | 触发 12/15/18/21/24/27/30%；增益时长 4/5/5/6/6/7/8 秒 |
| 九龙离火罩 | 护甲 +2/+2/+3/+3/+4/+4/+5；元素抗性 8/10/12/14/16/18/20%；背包 +8/+10/+12/+14/+16/+18/+20 |

详情页 / 悬停提示里会随等级变化的数值用金色显示。

## 死亡不掉落

六件法宝都带原版 `DontDropOnDeadInSlot` 标签（与图腾的实现一致），
装在法宝槽里时角色死亡不会掉落，背包里未装备的法宝不受影响。

## 触发提示

所有法宝触发时会在屏幕中上方弹出一条提示（图标 + 金色法宝名 + 具体效果），
淡入淡出约 2.7 秒，最多同时显示 5 条。字体直接从游戏内正在使用的 TextMeshPro
组件上取，圆角底图运行时生成（深色半透明 + 金色描边）。实现见 `src/UI/TreasureNotice.cs`。

## 法宝任务与宝箱

在 Jeff 处可**同时接取** 6 个任务，每个任务奖励 1 个「法宝宝箱」。
宝箱不可堆叠、使用一次消耗一个，使用后可从六件法宝中**任选一件**。

| 任务 | 目标 |
| --- | --- |
| 锋芒试炼 | 任意对局累计击杀 3 种不同的 BOSS 生物，并成功撤离 |
| 续航突围 | 单局开局不带备用弹药，击杀 ≥7 名敌人，并成功撤离 |
| 清浊除厄 | 单局受到 ≥3 种不同的异常状态（不含出血 / 骨折 / 创伤） |
| 濒死生还 | 单局血量降至 10% 以下 ≥2 次，不阵亡并撤离 |
| 坚忍之守 | 单局累计承受伤害 ≥400，活着撤离 |
| 满载而归 | 单局撤离带出的背包物资总价值 ≥60 万 |
| 初来乍到 | 成功从零号区撤离一次 |

- 异常统计范围：中毒 / 弱毒 / 食物中毒、触电 / 冰冻 / 冻结 / 震慑、害怕 / 扰动 / 扭曲 / 碎裂
- 精英判定：原版精英图标 + 白名单（劳登的狗、机械蜘蛛、蝇蝇队员、行走菇、雇佣兵）
- 任务 ID 900001~900006，随存档保存

## 物品 ID 约定（重要）

- 本 mod **独占 `17350 ~ 17399`**（用户 2026-10-20 指定），其它 mod 不要使用该区间。
- 新增物品按登记表顺序占用 ID，**不复用、不跳号**。
- 物品一旦随 mod 发布，**ID 永远不能改**：玩家存档按 TypeID 记录物品，改 ID 会让旧存档里的法宝变成错误物品或消失。
- 每新增一件法宝，必须在 `src/TreasureIds.cs` 的「物品登记表」补一行：
  `ID | 常量名 | 游戏内名称 | 克隆用原版模板 | 备注`。
- 区间用满前先与用户确认是否扩展，不要私自改号。

## ID 冲突检测

加载六件法宝前逐个检查 TypeID（17350~17355）：

- **与其它 mod 已注册的动态物品撞号** → 该法宝**不注册**，避免覆盖对方物品；
- **与原版物品表里的条目撞号** → 同样不注册；
- 同一次加载中已在前面注册过的法宝不会误判。

发生冲突后，进入游戏时用原版提示条（`NotificationText`）逐条显示 **3 秒**：

> 法宝之力：ID 17350 与 Mod「XXX」冲突，「翻天印」未加载

冲突 Mod 的名称是反查出来的：用前置 0Harmony 内嵌的 Mono.Cecil 逐个读取已启用 mod 的 DLL，查找谁加载了该 ID 常量（启发式，数值恰好相同也会命中）；解析不到时退回显示物品原型名。完整冲突信息同时写入游戏日志。

限制：只能发现**在本 mod 之前**注册的同 ID 物品；后加载的 mod 仍会覆盖本 mod（`AddDynamicEntry` 先到先得/后到覆盖）。
